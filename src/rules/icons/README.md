# Sutairu Icons

## Add a new icon

To add a new icon, start from [icon-template.svg](./icon-template.svg). This file contains layers with basic shapes (triangles, circles, squares, etc.) that can be used for composition with your new icon. Draw your icon in the layer named `icon`.

Once you're ready, save your new icon in [/src/icons-raw/<icon-name>.svg](/src/icons-raw/). The file name will determine the Sutairu class name, e.g., `my-icon.svg` becomes `.i-my-icon`.
